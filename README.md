# wows-replay-parser

A parser for World of Warships replay files written in Golang. Supports features such as timestamped events, stat extraction, and video conversion.

## Features

- Easy to use Golang library for parsing World of Warships replay files.
- Easy to use CLI tool for extracting stats and converting replays to video.
- Exporting parsed data to a timestamped JSON format for events
- Extracting stats of the replay such as player performance, ship statistics, and battle outcomes.
- Converting replays to video format for easy sharing and viewing.
